## なぜ協力プレイで方程式が変わるのか

探索はスタミナのゲームで、反射神経のゲームではない。ソロだと注意力カーブはすぐ落ちる。最初の一巡は鋭く、二巡目は雑になり、三巡目にはすでに二度確認した同じ干し草を見つめている。人が加わるとそのカーブがリセットされる。誰かが見えなくなった区画に、新しい目を提供してくれるからだ。

もう一つの変化は感情面だ。失敗した一巡も、三人が「悪い一巡だった」と同意すれば痛みが減る。探索系ゲームのコミュニティ報告は一貫して同じことを示す。退屈さこそがポイントであり、共有された退屈はコメディになる。

| 要素 | ソロ探索 | 協力探索 |
|---|---|---|
| 注意力の持続 | 最初の一巡以降に急落する | 新しい目が加わるたびにリセットされる |
| 大きな山での速度 | 遅く、単線的 | 区画を分ければ速くなる |
| 見落とし | 多い——トンネル視野になる | 少ない——相互確認がミスを拾う |
| フラストレーション | 静かに積み重なる | 声に出して発散され、ユーモアで和らぐ |
| 最適なセッション長 | 短い集中プレイ | より長く、社交的なラン |

| 手順 | やること | 重要な理由 |
|---|---|---|
| 1. グループ人数を確認 | ストアページで現在のプレイヤー上限を確認 | 5人目の友達がメニュー画面を見つめるのを避ける |

## 実際に機能するコミュニケーション戦術

**A Game About Needle In A Haystack** の協力プレイで最もよくある失敗は、曖昧なコールアウトだ。山が巨大なとき「こっち」は何の意味もない。良いコールアウトは短く、位置情報があり、繰り返せる。

| コールアウトの種類 | 弱い例 | 強い例 |
|---|---|---|
| 位置 | 「こっち！」 | 「左端、上から三分の一、黒い塊の近く」 |
| カバー範囲 | 「そこはやったと思う」 | 「セクションBは2分前時点でクリア」 |
| 疑い | 「たぶんあそこ？」 | 「中央右に光る可能性、再確認が必要」 |
| 引き継ぎ | 「これやって」 | 「下の帯に移る、真ん中を頼む」 |
| 確認 | 「見つけた！」 | 「セクションDで発見確認——Dの探索を止めて」 |

どんなフレーズよりも大事な習慣が2つある。第一に、**何をクリアしたかを言う**。自分が何をしているかだけではなく——否定的な情報こそ、4人が同じ場所を再確認するのを止める。第二に、**発見は2回繰り返す**。騒がしいボイスチャンネルでは一度の「見つけた」は消え、半分のメンバーがさらに1分探し続ける。

## 分割統治：役割の割り振り

役割をゆるく割り振ったグループは、全員が同じことをするグループより成果が良い。正式な肩書きは不要だが、全員が自分の既定の役割を知るべきだ。プレイヤー体験から、この分担はほぼどの人数の **A Game About Needle In A Haystack** 協力セッションでもうまく機能する。

| 役割 | 仕事 | 向いている人 |
|---|---|---|
| コーラー | カバー範囲を記録し、ゾーンを割り当て、完了マップを維持 | 忍耐強く整理好きなプレイヤー |
| スイーパー | 一度に1ゾーンをゆっくり徹底的に進める | 細部重視のプレイヤー |
| スキマー | 素早く広く流し、怪しいものに印を付ける | 飽きやすい高エネルギーなプレイヤー |
| ベリファイア | グループが移動する前に印の場所を再確認 | 偽陽性を嫌う懐疑的なプレイヤー |
| クローザー | 最終確認を担当し、ゾーンの終了を宣言 | はっきりした声の持ち主 |

2人だけなら、コーラーとベリファイアを1人にまとめ、もう1人がスイープする。3人ならスキマーを加える。役割は増やすより減らすほうがうまくいく——6人全員がコーラーなしでスイープするのは混沌だ。

## 協力探索を沈めるミス

熱心なグループでもありがちな罠にはまる。注意したい。

- **密集。** 全員が同じ面白そうな場所に流れる。数分ごとにゾーンを声に出して読み直して修正する。
- **無言の探索。** 2分の沈黙は効率的に感じるが、実はカバー範囲を見失う最速の方法。
- **勝利への突進。** 1人が発見を叫び、確認前にグループが散らばる。まず確認、祝うのは後。
- **疲労の無視。** 長いセッションの最後の10分は、最初の30分より多くの誤コールを生む。休憩を取る。
- **終了条件なし。** 何をもって「完了」とするか事前に決め、目的のないつつき合いに尻すぼみしないようにする。

| 問題 | 症状 | すぐできる対処 |
|---|---|---|
| 密集 | 全員が一角にいる | ゾーンを声に出し、ローテーションする |
| 沈黙 | 2分以上コールアウトなし | コーラーが各ゾーンの状況を確認 |
| 偽陽性 | 存在しない光を追う | グループ移動前にベリファイアが確認 |
| 疲労 | クリア済みゾーンを繰り返し確認 | 事前に決めた休憩を実行 |

## 長時間セッションについてコミュニティ報告が示すこと

探索重視の協力ゲームのコミュニティ報告は一貫したパターンを示す。最もよく話すグループが最も早く終わり、静かなグループが最も早くやめる。ソーシャルな層は飾りではない——注意力を生かし続ける仕組みそのものだ。

プレイヤー体験はまた、**A Game About Needle In A Haystack** の協力プレイはマラソンより短く集中したランで最良になると示唆する。間に休憩を挟んだ2〜3回のきれいな探索は、1回の長い作業より勝る。投資した総時間より、注意力の質のほうが重要だからだ。セッションを終えたときに消耗ではなく鋭さを感じるなら、ペース配分は正しい。

もう一つ盗む価値のあるコミュニティの観察：セッションを録画しよう。失敗した探索のリプレイを見るのは、グループ全体が共有していた盲点を見つける最速の方法だ。20分を節約できるまでは馬鹿げて感じる。
